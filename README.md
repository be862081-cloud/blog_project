The Personal Blog Website is a simple and interactive website where users can create and publish blog posts, share their thoughts, and interact with other users through comments.

The website is a Personal Blog Website developed using HTML, CSS, and JavaScript. It allows users to publish their own blog posts and share comments. We also integrated a public API called DummyJSON Quotes API to displayr random inspirational quotes on the Home page. We use Local Storage to save posts and comments in the browser, making the website interactive and user-friendly.

1. blog_project1. Home Page – Displays the latest three blog posts and a random inspirational quote using a public API.
2. Blog Page – Allows users to create and publish blog posts with a title, name, and message.
3. Comment Section – Allows users to write comments and interact with published posts.
4. Local Storage – Saves blog posts and comments in the browser so they remain available after refreshing the page on the same browser.
5. Public API Integration – Uses DummyJSON Quotes API to display random inspirational quotes.
